# Trust Streamlit App

## Dependencies
- streamlit
- pandas
- numpy
- matplotlib
- plotly
- polars
- openpyxl
- kaleido
- statsmodels

## Usage 

1. Install the required dependencies using pip:
   ```
   pip install streamlit pandas numpy matplotlib plotly polars openpyxl kaleido
   ```
2. Run the Streamlit app:
   ```
   streamlit run trust_streamlit.py
    ```
